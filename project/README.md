# FlexFit Gym Maintenance Tracker

An internal web application for gym staff and technicians to record equipment issues, assign maintenance tasks, and track repairs across gym branches.

## Features
- **Staff Authentication**: Secure login for gym staff and management.
- **Maintenance Dashboard**: View active jobs, filter by status (Open/Resolved), and search by equipment or location.
- **Log Equipment Faults**: Submit repair requests with priority ratings.
- **Status Updates**: Mark resolved issues with a single click.
- **SQLite Database**: Lightweight and persistent local data storage.

## Tech Stack
- Python 3
- Flask
- SQLite3
- HTML5 / CSS3 / JavaScript

## Quick Start Guide

### 1. Install Requirements
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
python app.py
```

### 3. Open in Browser
Visit [http://127.0.0.1:5000](http://127.0.0.1:5000)
